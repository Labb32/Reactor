# Project Instructions

## Comments

- Write code comments and documentation comments in concise English.
- Comment only when intent, constraints, or non-obvious behavior needs explanation.
- Do not restate what the code already makes clear.

## Testing

- Do not create, modify, or run tests unless the user explicitly requests it.

## Versioning

- Increment the patch version for every bug fix.
- Add one Korean line for each fix under its version in `PATCH_NOTES.md`.
